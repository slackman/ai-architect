# Проверки и результаты

## Автономные тесты

Команда из корня репозитория:

```bash
mvp/.venv/bin/python -m pytest -q mvp/tests -c mvp/pytest.ini
```

Результат: **25 passed**. Тесты используют локальные хранилища и явные заменители
модели и индексов. Покрытие: авторизация, tenant/ACL, отзыв прав во время генерации,
загрузка и дедупликация, grounding, повторная индексация, точный поиск,
LangGraph, цитаты, маскирование PII, расчёты и файловые секреты.
Качество реальной модели оценивается отдельно на размеченном корпусе.

## Реальные хранилища и сквозной сценарий

`scripts/check_indexes.py` проверяет Qdrant retrieval, расширение Neo4j,
групповой ACL и tenant isolation с синтетическими векторами. Он удаляет только
созданные им записи. `scripts/check_persistence.py` сверяет PostgreSQL с MinIO.

Ранее `scripts/e2e_smoke.py` прошёл на Compose с OpenRouter и Qwen3.7 Flash:
договор, два акта (один PNG-скан) и платёж получили `ready`. Оригиналы,
скачанные через API, побайтово совпали с загруженными. Vector-only вернул один
источник. GraphRAG - четыре и три пути Neo4j. Расчёт: акты 250 000, платежи
100 000. Читатель не получил закрытые документы. Injection-запрос был заблокирован.
Прогон относится к более раннему снимку образа. Полный E2E последующих
изменений требует повторного запуска.

Отдельный запрос по `contract.pdf` к более позднему Compose-образу вернул
`answered`, цитату со страницы 1 и все восемь спанов Jaeger. Общая задержка -
2476,7 мс, `generate` - 2373,6 мс. Замер выполнен один раз. Для оценки p95 нужна серия запросов.
Результат: [ai-query-current-e2e.json](benchmarks/ai-query-current-e2e.json).

## Ограниченный нагрузочный замер

macOS arm64, Docker Desktop. Клиент и контейнеры на одном компьютере,
9 готовых документов и 2 пакета. Точная модель CPU и лимиты Docker не зафиксированы.
После трёх прогревочных запросов каждый endpoint измерялся 15 с при четырёх клиентах.
OCR, загрузка и LLM в этой нагрузке не выполнялись.

| Операция | HTTP 200 | RPS | p50, мс | p95, мс | Макс., мс |
|---|---:|---:|---:|---:|---:|
| Список документов | 3423 | 228,06 | 16,58 | 24,97 | 101,43 |
| Список пакетов | 3331 | 222,01 | 16,79 | 26,72 | 121,33 |

Исходный результат: [local-load.json](benchmarks/local-load.json).

## Границы выводов

- Корпус малый и синтетический.
- Recall, обоснованность утверждений и точность цитат на размеченном корпусе не измерены.
- p50/p95 полного AI-пути и итоговая стоимость API не измерены серией.
- Проверки ACL и injection охватывают ограниченный набор негативных сценариев.
