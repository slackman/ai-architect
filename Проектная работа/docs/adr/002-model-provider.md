# ADR-002: Внешняя мультимодальная модель и локальные эмбеддинги

## Контекст

Обработка сканов, извлечение реквизитов и ответы требуют вызовов моделей.
Для поиска по содержанию нужны векторные представления текста - эмбеддинги.

## Решение

`ModelGateway` вызывает модели через OpenRouter. В профиле MVP для OCR,
извлечения реквизитов и ответов указана `qwen/qwen3.7-flash`.
Эмбеддинги вычисляются локально через FastEmbed: multilingual MiniLM,
384 измерения.

## Альтернативы и причина выбора

Локальная LLM требует GPU и настройки сервера моделей. Внешний API позволяет
проверять обработку документов и ответы без этого оборудования.
OpenRouter даёт единый API для смены модели через настройки. В целевом решении
предусмотрены локальные модели через LiteLLM и vLLM.
Для эмбеддингов выбрана компактная многоязычная модель, работающая на CPU:
индексация и векторизация вопросов выполняются без внешнего API.

## Допущения и ограничения

В демонстрации используются синтетические документы. Сканы и контекст ответа
передаются провайдеру. Доступность, время ответа и расходы зависят от его API.
Сравнение качества моделей на размеченном наборе не проводилось.
При смене модели эмбеддингов нужны новая коллекция и повторная индексация.
