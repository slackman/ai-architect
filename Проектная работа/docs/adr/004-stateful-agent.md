# ADR-004: Управляемый workflow на LangGraph

## Контекст

Вопрос проходит поиск, проверку источников, расчёт и генерацию ответа.
При запрещённом запросе или отсутствии источников обработка должна завершаться
до вызова модели. Права и суммы определяются кодом.

## Решение

LangGraph задаёт путь `guard → retrieve → expand → validate → calculate → generate → output`
с условными остановками. Состояние содержит пользователя, найденные фрагменты,
расчёты и ответ. Суммы вычисляются через `Decimal`. Для вопроса о номерах
связанных актов предусмотрен ответ по проверенным реквизитам без вызова LLM.

## Альтернативы и причина выбора

Для этого числа шагов достаточно обычных функций с условиями.
LangGraph выбран для явного описания состояния, переходов и точек остановки:
каждый этап можно отдельно проверить и измерить.
Свободный выбор действий моделью добавил бы непредсказуемость в сценарий,
где порядок поиска и проверок уже известен.

## Допущения и ограничения

Граф хранит состояние одного запроса в памяти. Продолжение с последнего этапа
после перезапуска не реализовано. PostgreSQL сохраняет историю вопросов
и готовых ответов. Проверка идентификаторов цитат связывает ответ с найденными
фрагментами. Смысловая точность ответа отдельно не проверяется.
