# ADR-006: Обработка документов и разделение хранилищ

## Контекст

Оригиналы нужны для просмотра и сверки, реквизиты - для расчётов,
поисковые индексы - для отбора контекста. Пакет объединяет файлы одной загрузки.
Связи по договору строятся по содержимому документов.

## Решение

MinIO хранит оригиналы, PostgreSQL - пакеты, документы, реквизиты, фрагменты и аудит.
Текстовый слой PDF читается напрямую. Сканы проходят OCR через модель.
Значение реквизита принимается, если оно найдено в цитате указанной страницы.
Документ получает `ready` после записи в Qdrant и Neo4j.
Повторная загрузка определяется по SHA-256 в пределах tenant.

## Альтернативы и причина выбора

Оригиналы можно хранить на диске сервера. S3-хранилище выбрано, чтобы доступ
к файлам был отделён от процесса API. Хранение текста и реквизитов в PostgreSQL
позволяет проверять источники и права независимо от поисковых индексов.
Индексы содержат производные данные для поиска.

## Допущения и ограничения

Общей транзакции между хранилищами нет. При ошибке документ получает `failed`
и исключается из ответов. Повторная обработка заменяет прежние фрагменты
и записи индексов. Проверка цитаты подтверждает совпадение с извлечённым текстом.
Ошибки самого OCR выявляются при сверке с оригиналом.
Автоматическое восстановление индексов не реализовано.
