допущения и ограничения. Упоминания целевой архитектуры
уточняют отдельные упрощения, принятые для MVP.

| [003](003-graphrag.md) | Qdrant и граф связей Neo4j |
| [004](004-stateful-agent.md) | Управляемый workflow на LangGraph |
| [005](005-access-control.md) | Серверный доступ и проверки ответа |
