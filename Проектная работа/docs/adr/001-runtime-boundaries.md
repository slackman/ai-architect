# ADR-001: Одно API-приложение и Docker Compose

## Контекст

В MVP реализованы загрузка и обработка документов, поиск и ответы на вопросы с учётом прав бухгалтера и читателя.

## Решение

FastAPI раздаёт интерфейс и выполняет обработку файлов и вопросов в одном
процессе. Приём запросов, обработка документов и поиск разделены на модули.
Docker Compose запускает API, PostgreSQL, MinIO, Qdrant и Neo4j с постоянными
томами. Основной Compose публикует API на localhost. `compose.ip.yaml`
публикует порт 8080 на сервере для доступа по IP через HTTP.

## Альтернативы и причина выбора

Отдельный worker с очередью позволил бы обрабатывать документы независимо
от API, но добавил бы передачу заданий и управление их состоянием.
Один процесс сокращает настройку и позволяет проверить весь сценарий
без межсервисных вызовов. Compose описывает запуск всех зависимостей вместе.
В целевой архитектуре обработка документов
распределена между сервисами с обменом через Kafka.

## Допущения и ограничения

Приложение запускается в одном экземпляре. Одновременно обрабатывается один
пакет, файлы внутри него - последовательно. При запуске API незавершённые
документы переводятся в `failed`. Повторную обработку запускает пользователь.
Задания не сохраняются в отдельной очереди.
