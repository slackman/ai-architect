# Архитектурные артефакты

Проект демонстрирует работу с договором, актами и платежами: загрузку PDF/сканов,
поиск связанных документов, суммы, цитаты и разные права пользователей.
Корпус синтетический. Проводки и юридические выводы не входят в MVP.
